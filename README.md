# C# Study Projects

A meta-repository with C# learning projects.

This repository serves as a navigation page for individual projects completed as part of learning C#, .NET, object-oriented design, architectural approaches, and testing.

## Projects

| Project | Description | Main Focus |
|---|---|---|
| [Educational Program Builder](https://github.com/EpicWhal3/EducationalProgramBuilder) | A model of an educational program constructor with domain entities, authorship, object copying, and in-memory repositories. | Domain modeling, SOLID, GRASP, creational patterns |
| [Corporate Messaging System](https://github.com/EpicWhal3/CorporateMessagingSystem) | A message distribution system with different types of recipients, importance filtering, logging, and message status tracking. | Structural patterns, extensible architecture, mocking |
| [File System Management CLI](https://github.com/EpicWhal3/FileSystemManagementCLI) | A console application for navigating and operating on the file system: viewing the directory tree, reading, copying, moving, deleting, and renaming files. | CLI, command parsing, file system, testable architecture |
| [ATM System](https://github.com/EpicWhal3/ATMSystem) | An ATM system with user and administrative modes, PostgreSQL data storage, and separation of business logic from infrastructure. | Layered architecture, PostgreSQL, service layer testing |

## Skills Demonstrated

- C# / .NET
- Object-Oriented Programming
- SOLID, GRASP
- Design Patterns
- Unit Testing
- Mocking
- CLI Application Development
- File System Operations
- PostgreSQL
- Layered Architecture
- Separation of Domain and Infrastructure Logic
